# Helios Lightfield 1.0.1

Smooth animation on Fire TV.

## Fixes

- The scene now renders at about 55 frames per second on a 1080p Fire TV instead of about 8. It is drawn at a size that keeps the shading work per frame constant for each strand density, and the display scales it to full screen. The soft glow keeps the result close to the full-size image.

## Compatibility and verification

Requires Android 6.0 (API 23) or later and OpenGL ES 2.0, unchanged from 1.0.0. Checked on an Insignia Fire TV Edition (Fire OS 8.1.8.5, API 30): installed over 1.0.0 with the same signing certificate, selected, and run as the active screensaver at 54 to 55 frames per second with 4, 6 and 9 strands. Details are in the [verification matrix](../VERIFICATION.md).

## Installation and upgrade

Install with `python3 install.py --serial TV_IP:5555` or follow the [installation guide](../INSTALLATION.md). 1.0.1 updates 1.0.0 in place and keeps your settings. There are no breaking changes.
